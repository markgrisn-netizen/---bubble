# PanelTranslate AI — Browser Companion Extension (MV3)

إضافة متصفح مستقلة (Chrome / Edge / Brave Manifest V3) تسمح بالتقاط صفحات المانغا والمانهوا التي يفتحها المستخدم بنفسه في المتصفح وإرسال ملفات الصور مباشرة إلى تطبيق **PanelTranslate AI** دون أي محاولة لتجاوز جدران الحماية أو CAPTCHA أو قراءة ملفات الارتباط (Cookies).

---

## الصلاحيات المستخدمة (Least Privilege)
- `activeTab`: الوصول إلى التبويب النشط فقط عند تفاعل المستخدم مع الإضافة.
- `scripting`: حقن سكريبت الالتقاط وتحديد الصور داخل التبويب عند الطلب.
- `storage`: حفظ قائمة الصور الملتقطة وبيانات جلسة الربط محلياً فقط.
- `contextMenus`: إضافة أوامر النقر بزر الفأرة الأيمن لالتقاط الصورة الظاهرة.

> **الخصوصية والأمان:** لا تطلب الإضافة صلاحية `cookies` ولا تقرأ كلمات المرور أو رموز المصادقة الخاصة بالمواقع. تعتمد على **Pairing Token** مستقل بين الإضافة وتطبيق PanelTranslate AI.

---

## خطوات التثبيت والتشغيل

1. **بناء الإضافة (في حال التعديل أو التثبيت من الشيفرة المصدرية):**
   ```bash
   npm run build:extension
   ```
   سيتم توليد الحزمة الجاهزة داخل المجلد: `browser-extension/dist/` (أو يمكنك تحميل الحزمة مباشرة من زر **تنزيل إضافة المتصفح (.zip)** داخل وضع Browser Companion في التطبيق وفك ضغطها).

2. **التثبيت في Chrome / Edge / Brave:**
   - افتح الصفحة: `chrome://extensions`
   - فعّل **وضع المطور (Developer mode)** من الأعلى.
   - اضغط **تحميل إضافة غير مضغوطة (Load unpacked)**.
   - اختر المجلد `browser-extension/dist`.

3. **الربط والالتقاط:**
   - من داخل PanelTranslate AI، افتح نافذة **استيراد فصل جديد** واختر وضع **Browser Companion**.
   - اضغط **بدء جلسة Browser Companion** وانسخ **كود الربط (Pairing Code)**.
   - افتح صفحة الفصل في تبويب متصفحك (واجتز أي تحقق بشري أو تسجيل دخول بنفسك إذا تطلب الموقع ذلك).
   - افتح أيقونة الإضافة ← الصق كود الربط ← اضغط **Connect to PanelTranslate AI**.
   - استخدم أزرار الالتقاط (`Capture Current Image` / `Capture Visible Page` / `Select Image on Screen` / `Capture Next Page` / `Auto Collect`).
   - راجع الترتيب واحذف المكرر إن وجد، ثم اضغط **Send to Translator** لإرسال الصور مباشرة إلى محرر الترجمة.

## ملاحظة حول بيئات الاستضافة السحابية
في بيئات المعاينة المستضافة عبر المتصفح السحابي (مثل حاويات التشغيل عن بُعد)، لا يمكن لمتصفح الحاوية المدار تحميل إضافات خارجية أو فتح عنوان `chrome://extensions`، لذلك تم توفير الإضافة كمشروع مستقل مكتمل داخل `browser-extension/` مع حزمة ZIP جاهزة للتنزيل والتثبيت في متصفحك المحلي وربطها بعنوان التطبيق الفعلي.
